# 微信机器人命令使用指南

适用对象：联赛成员、球队负责人和已获授权的管理员。

## 一、先分清在哪里发送

| 发送位置 | 用途 | 谁可以使用 |
| --- | --- | --- |
| 已配置的联赛微信群 | 查询待进行赛程、查询自己的赛程、参与微信群球员拍卖 | 群成员；部分功能需要先在后台关联用户账号 |
| 与机器人微信的私聊 | 查询管理编号、录入比分、裁定晋级、转会和管理拍卖 | 已在后台关联微信的管理员 |

请将命令作为**单独一条文字消息**发送。文中的 `M1`、`T1`、`P1`、`A1`、`L1` 只是格式示例，实际编号以机器人当时的查询回复为准。`原因：`后面的说明应填写真实的操作原因。

如果机器人在群里没有回复，请先确认该群已启用相应功能；如果私聊提示“关联管理员账号”，请联系平台管理员完成关联。群成员的“关联用户”和“私聊管理员”是两种不同的关联。

上线前，管理员应在联赛工作区的**微信群机器人**页面选择目标群、启用所需功能，并为赛程查询选择赛事来源。需要使用`我的赛程`或群拍卖出价的成员，由平台管理员在**群机器人 → 对应设备 → 管理群成员**中核对微信标识并关联普通用户账号。群内拍卖还需先在后台准备相应批次和拍品。

## 二、微信群命令

群功能由管理员逐群配置。未启用的功能不会响应相关命令。

| 命令 | 作用 | 使用条件 |
| --- | --- | --- |
| `帮助` | 查看本群已启用的机器人功能 | 群已接入机器人 |
| `查询赛程` | 查询本群配置的赛事中尚未完成、已发布的赛程 | 本群启用赛程查询 |
| `我的赛程` | 只查询自己球队尚未完成的赛程 | 本群启用赛程查询；微信已关联有效用户账号，且该用户在本联赛有现役球队 |
| 纯数字，如 `120` | 对当前正在拍卖的球员出价 | 本群启用微信群拍卖；当前有进行中的拍品；微信已关联有效用户账号，且该用户在本联赛有现役球队 |

赛程时间按**北京时间**显示。`查询赛程`和`我的赛程`只展示待进行比赛，已经完成的比赛不会列在这里。纯数字消息只在拍卖期间按出价处理，出价是否有效以机器人确认回复为准；每次有效出价会将倒计时重置为 30 秒。拍卖最终成交或流拍结果由管理员审核确定。

群里发送`开始拍卖`、`暂停拍卖`、`继续拍卖`或`取消拍卖`不会执行管理操作。管理员应私聊机器人，并附上拍卖批次编号。

## 三、管理员首次使用

1. 使用准备关联的微信，**私聊**机器人发送`帮助`。
2. 平台管理员在后台进入**群机器人 → 对应设备 → 私聊管理员 → 刷新管理员候选**，核对微信昵称和微信标识，再关联对应的后台管理员账号。
3. 关联后重新私聊发送`帮助`，确认收到管理员命令说明。
4. 如果管理员可管理多个联赛，先发送`联赛`查看列表，再用`切换联赛 联赛名称或ID`选择。随后发送`赛季`并按需切换赛季。

同一台机器人可以关联多个管理员微信，但每个微信应关联自己的后台管理员账号。机器人按后台账号的实时权限处理命令；关联普通用户账号不会获得管理员权限。新增管理员关联成功后，正常情况下不需要重启机器人。

## 四、管理员私聊：查询与选择

| 命令 | 作用 |
| --- | --- |
| `帮助` | 查看当前可用的管理员命令 |
| `联赛` | 列出当前账号可管理的联赛及 ID |
| `切换联赛 联赛名称或ID` | 选择要操作的联赛，例如`切换联赛 Cell国服联赛` |
| `赛季` | 列出所选联赛的赛季及 ID |
| `切换赛季 赛季名称或ID` | 选择赛季，例如`切换赛季 CELL S1` |
| `赛程`、`赛程2`或`赛程 2` | 分页查看可录分的已发布比赛及 M 编号；不写页码时查看第 1 页 |
| `球队` | 查看当前联赛的现役球队及 T 编号 |
| `阵容 T编号` | 查看指定球队球员、P 编号及球员卡 ID，例如`阵容 T1` |
| `拍卖列表` | 查看最近 30 个本机器人尚未完成的微信群拍卖批次及 A 编号 |
| `拍卖 A编号`或`拍卖 A编号 页码` | 查看批次、目标群、拍品及 L 编号，例如`拍卖 A5 2` |

编号含义：`M` 是比赛，`T` 是球队，`P` 是当前球员归属，`A` 是拍卖批次，`L` 是拍品。请先查询编号，再发送变更命令；不要把页面上的“第几场”“第几位”当成这些编号。

## 五、管理员私聊：录分与赛事管理

| 命令格式 | 示例 | 作用 |
| --- | --- | --- |
| `报分 M编号 主队比分:客队比分 原因：说明` | `报分 M1 2:1 原因：双方核实赛果` | 预览录分；比分顺序始终是主队:客队 |
| `晋级 M编号 主队/客队 原因：说明` | `晋级 M11 主队 原因：核实对手弃权` | 预览裁定晋级；不记录比分，签表按赛事规则推进 |

操作步骤：先发送`赛程`找到正确的 M 编号，核对赛事、轮次、主客队，再发送命令。机器人会回复“尚未提交”的预览及确认码。核对无误后，在 **2 分钟内**发送`确认 确认码`；如需放弃，发送`取消 确认码`。确认码必须使用该次预览中给出的实际值，例如`确认 A1B2C3D4E5F6`。预览过期后重新发送原命令获取新确认码。

录分可能更新积分或淘汰赛签表；晋级裁定只适用于符合赛事规则的比赛。若比赛状态已变化或不允许当前操作，机器人会拒绝，并提示重新查询。

## 六、管理员私聊：转会

命令格式：

```text
转会 P编号 T转出球队编号 T转入球队编号 金额 原因：说明
```

示例：

```text
转会 P1 T1 T2 50 原因：双方确认转会
```

先发送`球队`和`阵容 T编号`，核对球员、球员卡、转出队和转入队。机器人会预览转会金额、手续费、工资等执行结果；核对后在 2 分钟内发送预览里的`确认 确认码`。金额使用**后台系统金额单位**。转会须符合当前赛季、球队状态、工资及财务规则；条件变化时需重新预览。

## 七、管理员私聊：拍卖管理

拍卖批次及拍品需先由管理员在后台创建和准备，并配置目标微信群。以下命令用于**微信群拍卖渠道**；小程序拍卖渠道的出价按小程序页面操作。

| 命令格式 | 作用 |
| --- | --- |
| `开始拍卖 A编号` | 预览开始指定批次 |
| `暂停拍卖 A编号` | **立即暂停**指定批次，无需再发送确认码 |
| `继续拍卖 A编号` | 预览继续已暂停的批次，保留剩余倒计时 |
| `取消拍卖 A编号 原因：说明` | 预览取消批次；未结束拍品作废，待审核记录仍需处理 |
| `恢复拍卖 A编号 原因：已核对群消息` | 人工核对异常发送任务后，预览恢复并重新开始当前拍品的 30 秒倒计时 |
| `审核成交 L编号` | 预览确认拍品的待审核结果 |
| `调整成交 L编号 T球队编号 金额 原因：说明` | 预览调整待审核的成交球队和价格 |
| `作废成交 L编号 原因：说明` | 预览作废待审核结果 |

除`暂停拍卖`外，以上变更均按预览中的确认码在 2 分钟内确认。审核成交可能完成球员入队及账目结算，请核对 L 编号、球队和金额。机器人会在目标群发布开拍、有效出价、倒计时和结果消息；倒计时结束后，最终结果仍以管理员审核为准。遇到机器人连接或发送状态异常时，拍卖可能自动暂停并要求人工核对，切勿仅凭群消息重复执行恢复。

## 八、确认码与常见提示

| 私聊命令或提示 | 含义与处理 |
| --- | --- |
| `确认 确认码` | 提交刚刚预览的操作。相同确认码重复发送不会重复执行业务操作 |
| `取消 确认码` | 放弃尚未确认的预览，不执行业务操作 |
| `操作 确认码` | 查看尚未完成操作的状态或预览内容 |
| “确认已过期” | 超过 2 分钟；重新发送原命令并使用新的确认码 |
| “请关联管理员账号” | 由平台管理员在后台“私聊管理员”关联当前微信；不要用普通群成员的“关联用户”代替 |
| “没有可管理的联赛” | 核对后台管理员账号状态和联赛授权 |
| “请先选择联赛/赛季” | 先发送`联赛`或`赛季`，再发送相应的切换命令 |
| 群内发命令无回复 | 核对是否发在已绑定的群、该群是否启用相应功能，以及机器人设备是否在线；管理员管理命令应发私聊 |

使用有财务、赛果或球员归属影响的命令时，请完整阅读机器人预览，确认编号、联赛、赛季、主客队或球队、金额和原因后再提交。
