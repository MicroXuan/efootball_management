# 管理员私聊录分实施计划

遵循 specs/2026-10-26-wechat-private-admin-design.zh-CN.md，当前仅实现录分。
在 dev 原地开发，保留其他改动。按 executing-plans 与 TDD 实施，末尾独立审查。

1. 契约及迁移：独立管理员私聊联系人/绑定、比赛持久短号、预览确认操作；默认关闭的功能开关。
2. 后台：平台管理员从主动私聊帮助的候选绑定 AdminAccount、版本/幂等/审计、解除绑定撤销未确认操作。
3. 私聊命令：帮助、联赛/赛季选择、赛程分页、报分预览、确认/取消/操作查询；权限再次验证、事务锁与现有 applyAdministratorResult 同事务提交，操作状态作持久回执。
4. Bridge 与后台入口：窄私聊命令过滤、仅主动联系人可回复；设备管理独立管理员绑定面板。
5. 隔离数据库迁移/集成、相关既有入口回归、Bridge测试、独立审查及部署验收文档。

关键裁定：比赛编号 M + 自增引用号；确认码12位随机十六进制；后台不手输微信号而只选择帮助候选；更正及首次报分均要求原因以匹配既有正式录分契约。读写均以 AdminAccount 实时权限为准；确认在 ReadCommitted 事务内锁设备、联系人、管理员、联赛权限、预览，再调用既有比赛锁与正式录分。发布/窗口原规则不绕过。目标共享库不执行迁移/造数；本机 verify 库验证。
