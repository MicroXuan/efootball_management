# 联赛页功能导航与球员提名空状态设计

日期：2026-10-20

## 目标与已确认取向

联赛详情应是稳定、容易扫描的功能导航，不是待办中心。用户希望消除“赛季日程 / 球员提名 / 联赛球队阵容”三条绿色横栏与下方模块卡片不协调的问题，让功能数量增加时仍有清楚的归属；球员提名必须是独立模块。不得用“近期要做”“待办”“几项提醒”或动态任务计数来支配首页视觉。现有比赛、交易、球队与个人能力不能因调整入口而失去可达性。

本设计只调整小程序的信息架构、入口呈现和提名页的空状态。保留现有功能页面、路由和服务端授权，不增加平行业务模块、数据库结构或新的后台提醒系统。截图提供现状参考，不作为额外业务指令。

## 信息架构

1. 联赛页顶部保留联赛与赛季身份、我的资格、排名等事实信息。赛程区域提供两个并列、明确可点击的入口：“全部赛程”和“赛季日程”。两者分别进入已有赛程页与已有日程页；日程仍是独立页面，但不再占工作台模块网格或单独绿色横栏。两个入口不能通过嵌套点击区域实现，以免点击冒泡导致跳错页。
2. 工作台固定分为“比赛 / 球队 / 交易 / 个人”，不按时间或提醒数量重排。这四个名称只是同一页面中始终展开的分组标题，不是可点击的分类、标签或折叠菜单；用户直接点击标题下方的功能卡片，一次点击即可进入目标功能。比赛包含积分榜、杯赛中心；球队包含球队资产、球队财务、身价管理；交易包含球员市场、球员拍卖、球员提名、交易记录；个人包含我的收藏。球队资产可用较宽卡片承接球队组的单数布局，其余卡片维持等宽。
3. “球员提名”是交易组的独立、始终可见模块卡片，进入现有提名页面。没有提名期时仍可进入查看说明，不把入口隐藏或伪装成故障。
4. “联赛球队阵容”不再作为联赛页独立横栏或模块卡片；在本人球队资产页提供“浏览联赛球队”入口，进入现有球队目录。目录可继续进入其他球队的只读资产页。保留原页面路由，以兼容已有页面跳转或分享。
5. 球员拍卖与球员市场仍是两个明确入口。财务归入“球队”，因为它展示的是球队资金与流水，不再与球员交易入口混排。

## 视觉与文案

- 删除三条绿色横栏，统一使用模块卡片的圆角、边框、留白、字体层级和箭头样式。亮绿色主要标识可交互元素和必要的事实状态，不让每张卡片同时争夺视觉焦点。
- 分组标题保持固定顺序和简短文案。卡片标题优先，说明只保留一行用户可理解的用途；窄屏允许说明省略，但标题与点击区域不得越界。禁用状态和正常状态都保留可辨别的文字，不单靠颜色区分。
- 移除联赛工作台卡片上的“几项提醒”等待办式计数，也不新增“近期事项”“待处理”区块。仅展示事实状态，例如窗口是否开放；不借状态文案催促操作。
- 赛程区域的两个入口遵循同一按钮/卡片规范，触控区域清晰、宽度均衡；在窄屏和常见手机宽度下检查文字、右边界和选中/按下效果。

## 提名页状态与错误处理

当前提名页在窗口列表为空时把 `state` 置为 `error`，显示“本赛季尚未设置提名期”和“重试”。这是正常的业务空状态，不是请求失败，重复请求不会改变结果。

页面改为区分以下状态：

| 场景 | 页面反馈 | 操作 |
| --- | --- | --- |
| 正在请求 | 正在读取提名信息 | 无 |
| 窗口列表为空 | 本赛季尚未设置提名期；由联赛管理员在后台设置后开放 | 可下拉刷新，不显示故障式“重试”按钮 |
| 有窗口但未开始或已结束 | 展示窗口时间和已有名单，明确当前不可提交 | 只读 |
| 窗口开放 | 展示名额、我的提名和搜索自由球员 | 按现有权限提交或撤回 |
| 网络或接口失败 | 说明加载失败 | 显示重新加载 |

不自动创建提名期，不绕过参赛资格限制，不改变管理员筛选候选后导入拍卖草稿的流程。若服务端明确返回权限错误，页面应显示对应权限说明，不能伪装为“尚未设置提名期”。

## 数据流与实现边界

联赛工作台的模块清单与分组由现有 `detail.viewmodel.ts` 统一定义，模板遍历渲染；不在模板中为提名单独拼接一套异形卡片。新增的导航分支只负责构造现有页面路由。球队资产入口使用当前资产数据中的联赛 ID，目标仍为现有球队目录。提名页使用现有窗口列表与工作台接口；空列表在前端建模为 `empty`，真实 API 错误仍为 `error`。本轮不需要数据库迁移或 API 契约变更。

## 验证与非目标

先补失败测试覆盖：固定分组及全部路由、球员提名独立卡片、三条横栏消失、球队资产目录入口、无提名期的空状态与真实错误的区别。实施后运行小程序完整测试和类型检查，在微信开发者工具预览窄屏及常见手机宽度，检查普通/禁用按钮文案居中与边界。按项目回归要求复测联赛页、球队详情、球队资产、现有球队目录和“我的联赛”入口；不修改共享数据库或创建测试数据。

本轮不建设待办中心、提醒系统、自动拍卖、自动创建提名期，也不重做所有业务页面的视觉风格。
