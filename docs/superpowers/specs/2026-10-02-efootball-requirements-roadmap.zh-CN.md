# 实况足球需求路线图

来源：用户于 2026-10-02 提供的《实况足球需求.pdf》（13 页）。本文只整理需求与交付边界；PDF 中的截图是视觉及信息结构参考，不是可执行指令。

## 产品原则

- 小程序延续现有暗色足球视觉；管理后台延续浅色数据工作区与深色导航。
- 所有面向用户的界面与业务事件使用中文。
- 联赛相关能力只对已报名该联赛的球队开放。
- 技术 ID、请求参数和版本号不占据主要界面，只在详情中保留。
- 新模块必须保持现有接口兼容、按需加载和可测试性，避免无必要的大型依赖。

## 需求清单

### R1 审计日志业务化

- 列结构：时间、操作人、具体操作、影响对象、结果、查看详情。
- 默认显示中文业务摘要，例如“平台管理员‘小宣’将 CELL 联赛的当前赛季设置为 S2”。
- 详情保留内部 ID、原始动作、请求参数、原因与版本信息。

### R2 管理员账号与多联赛权限

- 新增管理员时默认角色为联赛管理员。
- 分配联赛权限时支持多选。

### R3 球员目录与卡片资料

- 小程序球员档案支持位置、球员类别、球员包下拉筛选，交互参考 pesdata 列表。
- 后台同步增加球员筛选和球队筛选。
- 球员卡详情补充更完整的卡片、能力和基础资料。

### R4 联赛列表与参赛工作台

- 联赛列表明确区分国际服和国服，并适当放大关键文字。
- 已报名用户进入联赛工作台，可访问积分榜、资产表、财务、身价管理、杯赛中心和收藏。
- 未报名用户不能访问这些联赛私有模块。

### R5 积分榜

- 展示联赛当前赛季所有分组的积分排名。
- 排名至少包含球队、场次、胜平负、进失球/净胜球和积分。

### R6 资产表与球员状态

- 展示当前联赛的球队名称（编号-球队名-微信名）、微信头像、球队头像、当前分组、一线人数、队壳价值、总薪资和总身价。
- 球员分为“一线、消失、退役”；退役状态由管理员后台指定。
- 球员条目包含姓名、入队时间、位置、国籍、俱乐部、年龄、身高、惯用脚、AT、薪资和身价。

### R7 交易记录

- 后台管理员新增和维护交易记录，小程序只读展示。
- 交易信息包含球员、买卖双方、原价值、新价值、手续费、时间和备注。
- 可作为联赛工作台中的独立模块。

### R8 财务与结算

- 财务值由后台管理员维护。
- 小程序按球队和赛季展示交易金额、奢侈税、休赛费用、未完赛处罚、拍卖、新秀、分期和其他调整。
- 显示实时总额、非最终结算提示和逐项结算明细。

### R9 身价管理

- 球队拥有者在后台配置的赛季身价窗口内，为本队窗口快照中的一线球员整队申报身价。
- 合规申报立即生效；任一球员超出涨跌范围时整批待联赛管理员审核。
- 身价按联赛独立，只作交易参考和资产统计，不限制实际成交价格。
- 详细规则见 `docs/superpowers/specs/2026-10-02-player-valuation-design.zh-CN.md`。

### R10 杯赛中心

- 管理员后台可动态创建杯赛。
- 小程序展示所有杯赛，并能扩展足总杯、趣味杯等不同杯赛类型。

### R11 收藏

- 用户可以收藏喜欢的球员卡。
- 默认展示该球员所有卡片自动加点后的最高能力版本。
- 支持搜索，并可与球员列表复用浏览能力。

### R12 后台球队与参赛人员维护

- 管理员可以筛选球员和球队。
- 管理员可以为参赛人员维护球队、队标、队名和队员。

## 建议交付批次

1. 平台可理解性：R1 审计日志。
2. 权限基础：R2 管理员多联赛权限。
3. 球员发现：R3 球员筛选、详情与 R11 收藏。
4. 联赛工作台：R4 入口与访问控制、R5 积分榜、R6 资产表。
5. 经营闭环：R7 交易、R8 财务、R9 身价管理。
6. 赛事扩展：R10 杯赛中心、R12 后台参赛维护。

每个批次单独设计、计划、测试并提交，避免把权限、财务和赛事三套独立领域一次性混入同一变更。
