# 后台管理系统本地开发与验收

## 启动

```bash
pnpm dev:db
pnpm db:migrate
pnpm start:api
pnpm --filter @efm/admin-web dev
```

后台默认访问 `http://127.0.0.1:4173/login`，API 为 `http://127.0.0.1:3000/v1`。使用种子脚本创建的平台管理员账号登录；密码只保存在本地环境或密码管理器，不写入文档。

## 完整验收路径

1. 平台管理员创建后台管理员账号和联赛，并授予该管理员联赛权限。
2. 联赛管理员按 6 位用户编号查找用户，创建该联赛专属球队并分配易记球队编号。
3. 设置工资帽和 DT 工资档次，先查看影响预览再发布。
4. 创建赛季转会窗口，并分别启用购买、出售、队间转会和卡片升级权限。
5. 在球队详情进入阵容管理：搜索球员，确认系统推荐的最高自动加点卡，也可展开查看其他卡。
6. 购买球员，核对 `当前人数/25` 和 `当前工资/工资帽`；同一真实球员不能被同联赛另一球队获得。
7. 在窗口内执行队间转会与卡片升级，确认工资重新计算；窗口关闭时按钮必须禁用。
8. 打开财务流水，确认记录只有查看能力，没有编辑或删除入口。
9. 在小程序“我的 → 联赛球队”查看同一用户在不同联赛的独立球队、阵容、工资、流水和当前窗口。

跨联赛访问、超 25 人、工资超帽、缺少 DT 自动加点结果和重复真实球员都必须由 API 拒绝。
