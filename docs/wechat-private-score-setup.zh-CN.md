# 管理员私聊录分：启用与验收

本期只开放录入/更正比分；录入晋级、转会不在本次范围。群聊查询与原用户关联继续独立运行。管理员微信必须关联 AdminAccount，普通 User 关联不授予管理权。仅平台管理员维护绑定；联赛管理员只能操作其未撤销授权的联赛。

## 部署顺序

1. 停止 Windows Bridge，安排 API 更新窗口。核对目标数据库主机及库名，并按现有部署规范备份。不要将共享库用于下面的验证造数。
2. 服务端更新 dev 代码后，在项目根目录、已明确选择部署数据库的终端运行：

```sh
pnpm db:status
pnpm db:migrate
pnpm db:status
pnpm db:generate
```

待应用迁移包含 `20261027150000_wechat_private_score`；检查所有迁移均已应用后再启动新 API。`db:migrate` 使用受控的 `migrate deploy`，不可换成 `db:migrate:dev`。若为本次迁移临时 export 了 DATABASE_URL，完成后执行 `unset DATABASE_URL`，避免后续命令误用；确认 API 自己的部署配置仍指向预期库。
3. API 环境增加 `WECHAT_BOT_PRIVATE_SCORE_ENABLED=true`，重新启动 API 与管理后台。该功能默认关闭；关闭可停止新的私聊录分，不删除已有比分。迁移保留，不回滚删表。
4. Windows 停止旧 Bridge 后更新（仅在本次提交已推送 dev 后执行）：

```powershell
cd D:\workspace\efootball_management
git pull --ff-only origin dev
cd apps\wechat-bridge
uv sync --extra windows
uv run efm-wechat-bridge --config .\bridge.toml doctor
New-Item -ItemType Directory -Force .\logs | Out-Null
$bridgeLog = ".\logs\private-score-$(Get-Date -Format yyyyMMdd-HHmmss).log"
uv run efm-wechat-bridge --config .\bridge.toml run --enable-send 2>&1 | Tee-Object -FilePath $bridgeLog
```

保留现有 `bridge.toml` 和令牌配置，不需要重建设备。

## 首次绑定

管理员使用自己的微信私聊机器人发送 `帮助`。平台管理员打开：**平台管理 → 群机器人 → 对应设备 → 私聊管理员 → 刷新管理员候选 → 管理关联**，核实稳定微信标识，选择后台管理员账号并提交。备注选填，不使用验证码，也不复用普通用户绑定。

显示全部已绑定管理员和最近 100 位未绑定候选。若候选过多没找到，让该管理员重新私聊“帮助”刷新到前列。一个设备下一个管理员只能关联一个微信；换绑/解绑取消其待确认操作。机器人换登录账号后设备停用、原管理员绑定撤销，须为新账号建立设备与绑定。

## 操作示例

逐条私聊发送（名字、编号及确认码以机器人实际返回为准）：

```text
帮助
联赛
切换联赛 CELL联赛
赛季
切换赛季 第一赛季
赛程
报分 M12 2:1 原因：双方比分核实一致
确认 AABBCCDDEEFF
操作 AABBCCDDEEFF
```

`M12` 是机器人返回的持久比赛短号；比分固定为系统主队:客队，不拼接球队编号。原因必填，0–99 分。报分先返回联赛、赛季、主客队、原比分、新比分的预览，2 分钟内确认才写入。放弃用 `取消 确认码`；过期重新报分。重复确认同一操作仅返回已完成结果。

确认时重新校验权限、绑定版本和比赛版本。其他人修改比赛、撤销权限、解绑、停用账号均不能继续使用旧预览。正式写入复用现有比分/积分/淘汰赛签表业务事务和审计。

## Windows 与目标环境验收（尚需实际执行）

先在隔离测试联赛做一次正式验收，选用可恢复的测试比赛，保留日志：

- 未关联管理员私聊不能写入；普通 User 关联不能获得权限；群聊报分不写入。
- 管理员私聊赛程正确；预览时后台比分未改变。
- 核对预览后确认：后台比分/积分/审计正确；群聊无管理回复；另一个私聊及群聊无误发。
- 再发相同确认码：结果相同，比分版本和审计不重复增加。
- 两份预览之一确认后，另一份旧预览被拒绝；超时、取消、撤销授权、解绑后旧码均不能写入。
- Bridge 重启后仍能处理主动私聊者待发回复；切换微信其他会话后仍准确定位管理员私聊。
- 原群聊帮助、查询赛程、后台现役/已退出球队和详情、小程序“我的联赛”继续可用。

代码侧已在本机隔离库测试；不等同于共享数据库、Windows GUI 以及微信实机验收完成。测试数据须按精确记录清理并复查。
